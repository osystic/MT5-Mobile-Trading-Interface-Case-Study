# MT5 Mobile Trading Interface

## P — Problem & constraints
Create a mobile interface for core MT5 account/market workflows while working through a REST integration boundary.

## A — Architecture & decisions
Expo/React Native UI -> MT5 service abstraction -> external MT5 REST provider -> broker account.

## C — Contribution & delivery
Delivered quotes, trade, chart, history, account and settings interfaces plus service functions for connection/account/order/symbol data.

## E — Evidence & outcomes
The private source demonstrates the implemented UI and integration capability. It does not evidence profitability or a production-hardened credential architecture.

## Confidentiality
Public proof excludes source, credentials, tokens and live account data.
